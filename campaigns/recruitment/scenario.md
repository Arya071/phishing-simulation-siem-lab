# SIM-001 — Recruitment / Internship

## Scenario ID

SIM-001

## Campaign Name

NexaCore Early Careers

## Objective

Evaluate whether test participants interact with an unexpected
internship-related email containing a simulated link.

## Scenario

A fictional NexaCore Early Careers department sends a message
informing the recipient about a technology internship opportunity.

The message directs the recipient to a simulated opportunity page.

## Sender

NexaCore Early Careers

## Sender Address

earlycareers@nexacore.example

## Subject

Technology Internship Program — Application Update

## Primary Psychological Technique

Opportunity and curiosity.

## Secondary Techniques

- Career relevance
- Professional context
- Action-oriented messaging

## Primary CTA

Review Opportunity

## Security Indicators

1. Unexpected recruitment communication
2. Link-based action
3. Sender identity should be independently verified
4. Recipient is encouraged to act on the message
5. The opportunity creates curiosity and perceived value

## Expected User Behavior

A security-aware participant should:

1. Inspect the sender.
2. Consider whether the message was expected.
3. Examine the destination before following the link.
4. Independently verify the opportunity if necessary.
5. Report suspicious communication through the appropriate channel.

## Data Collected

The simulation records only behavioral events:

- Email delivery
- Email opening
- Link click
- Reporting behavior
- Event timestamps

## Credentials

No passwords, authentication tokens, MFA codes, or other
authentication information are collected.

## Landing Page

The landing page presents a simulated internship opportunity
and subsequently explains that the interaction was part of an
authorized security-awareness exercise.

## Security Lesson

Recruitment-related messages can exploit career motivation and
curiosity. Users should independently verify unexpected
opportunities and inspect links before interacting with them.

## MITRE ATT&CK Mapping

Primary technique:

T1566 — Phishing

The specific link-based behavior will be documented in the
final MITRE ATT&CK analysis.
