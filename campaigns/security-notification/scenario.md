# SIM-002 — Security Notification

## Scenario ID

SIM-002

## Campaign Name

NexaCore Information Security

## Objective

Evaluate whether test participants interact with an unexpected
security-related notification that uses authority and urgency.

## Scenario

A fictional NexaCore Information Security department sends a
notification asking the recipient to review a simulated security
notice.

## Sender

NexaCore Information Security

## Sender Address

security@nexacore.example

## Subject

Security Notification — Account Review Required

## Primary Psychological Technique

Authority and urgency.

## Secondary Techniques

- Security concern
- Fear of account disruption
- Action-oriented messaging

## Primary CTA

Review Security Notification

## Security Indicators

1. Unexpected security notification
2. Urgency
3. Authority-based sender identity
4. Link-based action
5. Request should be independently verified

## Expected User Behavior

A security-aware participant should:

1. Inspect the sender.
2. Determine whether the notification was expected.
3. Avoid acting immediately because of urgency.
4. Verify the message through an independent channel.
5. Report suspicious communication.

## Data Collected

Only non-sensitive behavioral events are recorded:

- Email delivery
- Email opening
- Link click
- Reporting behavior
- Event timestamps

## Credentials

No passwords, authentication tokens, MFA codes, or other
authentication information are collected.

## Landing Page

The landing page will present a simulated security notification
and subsequently disclose the awareness exercise.

## Security Lesson

Attackers frequently exploit authority and urgency to encourage
users to act before verifying a message.

## MITRE ATT&CK Mapping

Primary technique:

T1566 — Phishing

The final report will document the applicable phishing
sub-technique.
