# Wazuh Dashboards

## SIM-001

The current evidence demonstrates that Rule `100012` can be filtered and investigated in the Wazuh interface. A dedicated multi-scenario dashboard is future work rather than a completed feature.

## Planned Views

As SIM-002 and SIM-003 are implemented, useful visualizations include:

- alerts by simulation ID;
- alerts by rule and severity;
- event timeline;
- scenario comparison;
- detection counts;
- detection latency, where timestamps support a defensible calculation.

Dashboard metrics should distinguish technical validation runs from genuine multi-user awareness studies.
