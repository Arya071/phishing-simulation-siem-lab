## Usage

The timeline should tell the story in chronological order:

1. Initial activity
2. Telemetry collection
3. Detection/alert
4. Follow-up activity, if any
5. Analyst conclusion

A timeline is not a list of unrelated alerts. Only events relevant to the investigated scenario should be included.
