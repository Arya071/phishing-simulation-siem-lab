## Visual Style

The visual identity should communicate:

- Enterprise technology
- Professionalism
- Innovation
- Trust
- Modernity
- Minimalism

## Email Structure

All simulation emails should use a consistent structure:

1. Corporate header
2. Campaign-specific hero section
3. Main message
4. Information card
5. Call-to-action
6. Security simulation disclosure
7. Corporate footer

## Landing Page Structure

All simulation landing pages should use:

1. Corporate header
2. Hero section
3. Main content
4. Scenario-specific information
5. Simulation awareness notice
6. Footer
