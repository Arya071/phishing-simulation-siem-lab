# Phishing Simulation Lab — Testing Scope

## Project Purpose

This project is an authorized cybersecurity awareness simulation
designed to study user interaction with simulated phishing messages
in a controlled laboratory environment.

## Testing Environment

The simulation is conducted using:

- Kali Linux
- GoPhish
- Mailtrap SMTP
- Controlled test accounts

## Authorized Targets

Only email accounts owned by the project operator or explicitly
authorized participants are included in the simulation.

## Data Collection

The simulation records non-sensitive behavioral metrics such as:

- Email delivery
- Email opening
- Link interaction
- Reporting behavior
- Campaign timestamps

## Explicitly Excluded

The project does not:

- Collect real passwords
- Collect authentication tokens
- Collect MFA codes
- Deploy malware
- Install software on target systems
- Target unauthorized users
- Attempt account compromise
- Impersonate real employees

## Phishing Simulation Scenarios

Three simulated scenarios will be evaluated:

1. Recruitment / Internship
2. IT Security Notification
3. Document Sharing

## Purpose of Results

Results will be used to demonstrate:

- Phishing susceptibility analysis
- Social-engineering analysis
- Security-awareness measurement
- MITRE ATT&CK mapping
- Defensive recommendations
- SOC investigation methodology
