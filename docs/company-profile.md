# NexaCore Technologies

## Company Overview

NexaCore Technologies is a fictional multinational technology
organization created exclusively for the Enterprise Phishing
Simulation Lab.

The fictional organization provides enterprise technology services
across software engineering, cloud computing, cybersecurity,
artificial intelligence, and digital infrastructure.
